### 0.2 Риг кубика (обязательная иерархия)

```
cubeRoot      .position = (x, y, z)                    ← центр недеформированного куба
 └ squash     .scale    = (sxz, sy, sxz), sxz = 1/√sy  ← деформация в МИРОВОЙ вертикали
    └ rot     .rotation = (rx, ry, rz), order 'YXZ'
       │      rx = rx_pose + rx_flip,  rz = rz_pose + rz_flip
       ├ mesh RoundedBoxGeometry(1,1,1,6,0.18), центр в (0,0,0)
       └ face (передняя грань, z = +0.5): глаза, зрачки, блики, брови
              face.rotation.z = −rz_flip   ← глаза «наклейкой» остаются горизонтальными на кувырках
```

- Squash делается **над** поворотом — сплющивание всегда по мировой вертикали (и когда кубик
  лежит на «спине», и в наклоне). Объём: sx·sy·sz = 1.
- **Правило опоры (contact constraint):** пока кубик «на опоре» (в таблицах помечено `C`),
  `y` подбирается так, чтобы `Box3().setFromObject(cube, true).min.y` = высота опоры
  (1.20 крышка, 1.22 кант, 0.95 при застревании в треугольнике). Для прямостоящего кубика
  это просто `y = 1.2 + 0.5·sy` — значения в таблицах уже посчитаны по этой формуле.
- Каналы `*_flip` — «кувырок», сбрасываются в 0 в момент приземления (кубик симметричен при
  повороте на 90°/360°, а глаза противовращались → скачка нет).

### 0.3 Интерполяции

| Код | Кривая на сегменте u ∈ [0,1] от ключа до следующего ключа |
|---|---|
| `H` | держать значение (ступенька) |
| `L` | линейно |
| `EI` | easeInQuad: u² (разгон, падение) |
| `EO` | easeOutQuad: 1 − (1 − u)² (торможение, взлёт) |
| `S` | easeInOutSine: −(cos πu − 1)/2 |
| `B(hp)` | прыжок-баллистика: x, z — линейно; низ куба `y_низ = 1.2 + 4·hp·u(1−u)`; `y = y_низ + 0.5·sy` (hp — высота подъёма низа) |
| `F` | формула (см. §3.1) |
| `T` | таблица по кадрам (см. §2.3) |

Значения между ключами одного канала, не указанные в строке, **не меняются** (берётся
последний ключ этого канала). Ключ задан на кадре f и действует с этого кадра.

### 3.1 Формула падения-петли (f438–449 и f0–12)

> **Принятая формула (вариант B, мой расчёт):** τ = t − 14.6, где t = f/30, а для f < 30
> t = f/30 + 15:
> **y(τ) = 7.90 − 1.615·τ − 7.669·τ²** (g = 15.34 u/s², начальная скорость 1.615 u/s вниз).
> x = −0.68, z = −0.55 на всём падении. Контрольные значения: f438 7.900 (низ куба −25 px,
> ещё целиком над кадром) · f440 7.758 (низ +8 px — входит) · f444 7.270 · f449 6.277
> · **f0 6.027** (центр ≈ 226 px — как в сценарии) · f6 4.170 · f11 2.154 · **f12 1.700 = касание**.
> Для f < 438 кубик скрыт.

**Почему не исходная формула direction §8.1** (y = 7.47 − 9.02·(t − 14.6)², старт из покоя):
она совпадает с B на f0 и f12, но на f438 кубик уже на 75 px виден в кадре и **неподвижен**
(скорость 0) — он «возникает» в кадре скачком и 2–3 кадра «висит». Вариант B сохраняет все
условия сценария (кадр 0 ≈ 230 px, касание 0.4 с, «показывается у верхнего края на 14.6»,
кадр 449 на 1 кадр выше кадра 0) и вводит кубик в кадр уже в движении. Если режиссёр
настаивает на исходной — заменить только эту формулу и `p1/m1` в тени (§4.5); остальное не
меняется.

### 5.4 Композиция и правила
- Правило 180°: одна камера всегда на стороне +z; круг слева, квадрат справа на всём ролике.
- Монотонность одного плана компенсируется сменой действия каждые 0.5–1.4 с (16 битов,
  в среднем 0.94 с), двумя толчками (2.6 < 5.0), dolly-in в паузе и dolly-out к петле.
  Требование роли «2–4 с на кадр» относится к монтажным кадрам; здесь склеек нет, поэтому
  биты короче — это ритм действия, а не нарезка.
- Верх кадра (≈ 0–600 px) — мятный «воздух» для падений и прыжков; это поле движения, а не
  пустота: оно заполняется на f0–12, 69–78, 135–150, 183–195, 438–449.
