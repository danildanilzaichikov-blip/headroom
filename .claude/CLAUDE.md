# Память проекта (headroom)

Этот файл — долговременная память для всех сессий Claude в этом репозитории.
Обновляй его, когда пользователь сообщает новые предпочтения или принимаются решения.
Файл в `.gitignore` апстрима (`CLAUDE.md`) — коммитить через `git add -f .claude/CLAUDE.md`.

## Предпочтения пользователя
- Общение — **на русском языке**, коротко и по делу.
- **Автономность:** главный агент ведёт задачу сам и обращается к пользователю только по
  спорным моментам; не оповещать о каждом шаге (2026-10-29).
- Новые **идеи** роликов согласовывать с пользователем (предлагать 2–3 варианта на выбор).
  **Доработки/правки** по итогам проверки главный агент решает и вносит сам
  («Правки меняй ты»; согласование требовалось только в первый раз).
- Контроль качества всех этапов — отдельный субагент qa-supervisor; главный агент
  (youtube-analyst) фокусируется на анализе и результате.
- Можно создавать новых субагентов под задачи без согласования.
- Стиль: 3D в духе Disney/Pixar, мягкая «податливая» анимация — тела и руки
  деформируются при контакте (рукопожатие и т.п.), нет «каменных» движений; больше
  анимации; «играющая» камера, переключающаяся между персонажами.
- Ценит оригинальность идеи и честный ответ, если идея не оригинальна.
- Хочет, чтобы опыт всего диалога учитывался в следующих сессиях (этот файл).

## Видеопроизводство
- Агенты: `.claude/agents/` — youtube-analyst (анализ трендов + шоураннер), qa-supervisor (контроль),
  script-writer, director, shot-designer, voice-over, video-producer, video-editor,
  character-animator (персонажи, мягкая анимация, мимика, липсинк).
- Анализы трендов: `analysis/`; ролики: `production/<slug>/` (там же `qa-log.md`).
- Фокус: анимационные ролики YouTube Shorts / TikTok / Instagram Reels, 9:16, 15 с, петля.
- Конвейер: анализ → идея (согласовать) → сценарий → режиссура → раскадровка ‖ озвучка →
  тестовые кадры (показать/проверить) → полный рендер ‖ звук → сборка → qa-supervisor.

## Окружение (облако) — что работает и что нет
- Новые файлы агентов подхватываются только новой сессией; в текущей запускать их как
  general-purpose с указанием «прочитай .claude/agents/<роль>.md».
- Субагент не может запускать субагентов (вложенность 1 уровень). Для иерархии
  «старший → ведущие → их субагенты» — отдельные облачные сессии (create_session).
- Stop-hook требует коммитить и пушить все изменения в конце каждого хода.
- 3D: three.js r170 в headless Chromium (Playwright, WebGL2/SwiftShader) — ≈0.6 с/кадр
  1080×1920; Blender как Python-модуль `bpy` ставится с PyPI (для Cycles/Pixar-качества).
- Сеть: открыты PyPI, npm, apt; закрыты GitHub, Hugging Face, ElevenLabs, OpenAI,
  Яндекс TTS, Silero, Bing/Edge TTS, Google Translate. Учётки gcloud без разрешения
  пользователя не трогать.
- Речь: RHVoice через apt (`rhvoice rhvoice-russian`, 14 рус. голосов); эмоции —
  посегментный синтез с разной высотой/темпом/громкостью + междометия, паузы,
  растянутые гласные (`analysis/voice_test_emotions.py`). Пользователь решил оставить
  RHVoice; для нейроголосов нужен домен в Allowed domains и ключ в секретах окружения.
- Звук, музыка, SFX — синтез в numpy/scipy; мастер −14 LUFS, TP ≤ −1 dBTP.
- Прослушать звук в облаке нельзя. Встроенный плеер приложения Claude может играть
  видео без звука — давать пользователю отдельный MP3 для проверки и вариант 44.1 кГц.

## Уроки для следующих роликов
- Полный реестр проблем и решений — `analysis/issues.md` (сверяться перед каждым роликом).
- Делать тестовые кадры до полного рендера — первая версия была мелкой для телефона
  (камера ближе, глаза ×1.4, гэги крупнее).
- Ключевые эмоции должны достигать пика ровно на кадре звука (озарение f273).
- Субагентов независимых этапов запускать параллельно (озвучка ‖ раскадровка,
  звук ‖ доработка рендера) — экономит время.
- Проверять возможности окружения до обещаний (TTS, рендер, сеть) и сразу говорить
  об ограничениях.
- Не запускать CLI-скрипты с неизвестными флагами (`render.js --help` запустил полный рендер).
