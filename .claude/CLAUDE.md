# Память проекта (headroom)

Этот файл — долговременная память для всех сессий Claude в этом репозитории.
Обновляй его, когда пользователь сообщает новые предпочтения или принимаются решения.

## Предпочтения пользователя
- Общение — **на русском языке**.
- Новые **идеи** роликов согласовывать с пользователем. **Доработки/правки** по итогам
  проверки главный агент решает и вносит сам, без согласования (решение пользователя
  2026-10-29: «Правки меняй ты»; согласование требовалось только в первый раз).
- Контроль качества всех этапов — отдельный субагент qa-supervisor; главный агент
  (youtube-analyst) фокусируется на анализе и результате (решение пользователя 2026-10-29).

## Видеопроизводство
- Агенты: `.claude/agents/` — youtube-analyst (анализ трендов + шоураннер), qa-supervisor (контроль),
  script-writer, director, shot-designer, voice-over, video-producer, video-editor.
- Анализы трендов: `analysis/`; ролики: `production/<slug>/` (там же `qa-log.md`).
- Фокус: анимационные ролики YouTube Shorts / TikTok / Instagram Reels, 9:16.
- Технологии в облачном окружении: Blender нет; 3D — three.js в headless Chromium
  (Playwright, WebGL2 через SwiftShader), сборка — ffmpeg; TTS и AI-генераторов нет,
  звук синтезируется в Python/numpy.
